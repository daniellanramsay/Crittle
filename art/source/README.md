# Your source art

Put your Krita files here:

- `cat.kra`: your working file
- `cat.psd`: the export the game's build tool reads (Phase 5)

Everything in this folder except this note stays on your laptop. git ignores it because the GitHub repository is public. **Back these files up yourself**, for example to OneDrive or an external drive.

How to draw and name everything: `docs/ART-GUIDE.md`.
